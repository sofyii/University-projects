## Домашняя работа 3 - оценка кредитного риска
Задача бинарной классификации: необходимо оценить кредитный риск клиента и предсказать, насколько надёжным будет заёмщик

Датасет содержит информацию о финансовом положении клиента, его занятости, кредитной истории и других характеристиках

**Основные признаки:**
`status` — состояние текущего счёта;
`duration` — срок кредита;
`credit_history` — кредитная история;
`purpose` — цель кредита;
`amount` — сумма кредита;
`savings` — размер сбережений;
`employment_duration` — продолжительность занятости;
`installment_rate` — доля дохода, направляемая на погашение кредита;
`personal_status_sex` — семейное положение и пол;
other_debtors` — наличие созаёмщиков или поручителей;
`property` — имущество клиента;
`age` — возраст;
`housing` — жилищные условия;
`number_credits` — количество кредитов;
`job` — категория занятости;
`telephone` — наличие телефона;
`foreign_worker` — статус иностранного работника


Целевая переменная - `credit_risk`
- 0 — плохой кредитный риск (bad);
- 1 — хороший кредитный риск (good)

**Цель работы:** минимизировать выдачу плохих кредитов при совместной минимизации FP и FN
