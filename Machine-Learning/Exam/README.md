## Экзамен
Задача регрессии: необходимо предсказать стоимость спортивной сумки на основе её характеристик

Данные
- Brand — бренд сумки;
- Material — материал;
- Size — размер;
- Compartment — количество отделений;
- Laptop Compartment — наличие отделения для ноутбука;
- Waterproof — водонепроницаемость;
- Style — стиль сумки;
- Color — цвет;
- Weight Capacity (kg) — вместимость по весу в килограммах.

Целевая переменная: Price — стоимость сумки.

**Метрика качества:** RMSLE
