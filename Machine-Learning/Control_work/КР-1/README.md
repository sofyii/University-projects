## Контрольная работа 1
Задача многоклассовой классификации: необходимо предсказать вид пингвина (species) на основе его физических характеристик и данных наблюдений

Данные:
- bill_depth_mm - высота  клюва пигвина
- bill_length_mm - длинна  клюва пигвина	 
- body_mass_g	- вес пигвина в граммах
- flipper_length_mm	- длинна крыла пигвина
- island - остров наблюдения
- sex - пол
- year - год наблюдения
