## ИССЛЕДОВАНИЕ ГЕНДЕРНОГО РАЗРЫВА В ЗАРАБОТНЫХ ПЛАТАХ
Данные: `https://www.hse.ru/rlms/spss` 

Переменные:   
`wage` - среднемесячная зп  
`sex` - пол (бинарная)  
`age` - возраст     
`age^2` - квадрат возраста   
`status` - тип населённого пункта  (бинарная)    
`children` - количество несовершеннолетних детей    
`married` - семейное положение (бинарная)    
`is_supervisor` - есть ли подчинённые (бинарная)    
`sport` - занятия спортом (бинарная)   
`field of activity` - специальность(гуманитарная/техническая) (бинарная)  
`diplom` - наличие высшего образования (бинарная)   
`health` - показатель здоровья (бинарная)   
`language` - знание хотя бы 1 иностранного языка (бинарная)    
`working hours` - продолжительность рабочего времени
