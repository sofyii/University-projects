## Соревнование NLP
Датасет состоит из двух csv файлов с данными и файла для публикации ответа: sample_submission.csv. В файлах с данными сепаратор - "\t", в файлах с сабмитами - ",".

В файле train следующие поля:
`id` - айдишник строчки данных `source` - источник информации (категориальная переменная) `title` - новостной заголовок
`text` - текст новости `publication_date` - дата публикации новости `target` - лейблы новости

В папке test лежат те же поля, кроме таргета.

В sample_submission в поле `id` вы должны вписать id предсказания, а в поле `target` - ответ (разметку) в формате списка.
**Метрика соревнования** - hamming score
