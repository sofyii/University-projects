## Соревнование CV  

Датасет состоит из двух zip файлов с данными и файла для публикации ответа: sample_submission.csv.  
В файле train: images - папка с картинками тренировочного датасета labels - папка с разметкой тренировочного датасета
В папке test лежат только картинки тестового датасета.  
**Метрика соревнования** - AP по всем классам с порогом 0.5
